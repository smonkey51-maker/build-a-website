Un prompt che funziona una volta non è ancora un processo. Per renderlo ripetibile separa le parti fisse dalle variabili: il ruolo, il formato di output e le regole restano costanti, mentre il contenuto cambia a ogni richiesta.

Chiedi un formato strutturato, per esempio JSON con campi definiti. Così puoi validarlo automaticamente invece di leggerlo a mano.

Infine, conserva una piccola suite di esempi attesi e rilanciala a ogni modifica del prompt.
